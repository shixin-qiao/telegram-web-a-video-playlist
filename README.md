# Telegram Web A 视频连播器

一个 Tampermonkey 用户脚本，用于 [Telegram Web A](https://web.telegram.org/a/) 的媒体查看器：**视频开始播放时自动全屏，播放结束后自动连播下一个视频**，途中穿插的图片会被自动跳过。

## 功能

- **自动全屏**：视频（含 GIF 等循环视频）开始播放时自动进入整页全屏；循环视频会先关闭 `loop`，保证播放一遍后能触发结束事件。
- **自动连播**：当前视频播放结束后，自动切换到下一个视频并开始播放；连播期间保持全屏，不会「退出再进入」。
- **自动跳过图片**：连播切换途中遇到图片会自动继续往后找，直到下一个视频。
- **自动退出全屏**：播到最后一条视频、关闭媒体查看器、或你手动按 Esc 时退出全屏。
- **方向可选**：支持「下一条」和「上一条」两个方向，反向连播同样会跳过图片。
- **尊重手动操作**：你手动退出全屏后，本次查看器会话内不再自动全屏；关闭查看器重新打开后恢复。

## 安装

1. 安装 [Tampermonkey](https://www.tampermonkey.net/)（或其他兼容的用户脚本管理器）。
2. 点此安装脚本：[telegram-web-a-video-playlist.user.js](https://raw.githubusercontent.com/shixin-qiao/telegram-web-a-video-playlist/main/telegram-web-a-video-playlist.user.js)
3. 打开 https://web.telegram.org/a/ ，在媒体查看器中播放视频即可生效。

## 菜单命令

在 Tampermonkey 的脚本菜单中：

- **切换方向：下一条 ▶**
- **切换方向：上一条 ◀**
- **自动全屏：开 / 关**

## 规则说明

1. 视频开始播放 → 自动整页全屏。
2. 视频播放结束 → 保持全屏，自动切下一条；图片自动跳过，直到下一个视频开始播放。
3. 最后一条视频播完 → 退出全屏。
4. 关闭媒体查看器 → 退出全屏并重置状态。
5. 手动退出全屏 → 本次会话不再自动全屏（浏览器无用户手势时无法再次进入全屏）。

## 限制

- 全屏需要用户手势授权：正常从聊天点开媒体查看器时可以自动全屏；若浏览器拦截，手动点一下播放即可。
- 全屏对象是整页元素而不是 `<video>`，这样连播切换媒体时 Web A 重新渲染播放器不会打断全屏，也不需要无手势的二次全屏请求。
- 仅匹配 Web A（`web.telegram.org/a/*`），不支持 Web K。
- 主要面向 Chrome / Edge，其他 Chromium 内核浏览器理论上可用。
